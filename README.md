# Sistema_Trevo
Sistema de organização de fotos e vídeos por categorias e álbuns, com uma mini rede social fechada integrada aos álbuns, possuindo sistema de comentários aos colaboradores.
Apenas os colaboradores e o dono do álbum pode ver as fotos/vídeos e comentar nos mesmos ou nas categorias.

O projeto ainda não saiu do protótipo mas pretendemos evolui-lo aos poucos.
